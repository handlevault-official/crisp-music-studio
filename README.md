# Crisp Music Studio 🎵

A local-first, offline-capable music workshop and audio utility built for songwriters, beatmakers, and musicians. Part of the **Crisp Suite / HandleVault** ecosystem.

## ✨ Features

- **Chord Progression Generator:** Instantly generate popular, jazz, epic, and melancholic chord progressions across multiple root keys.
- **Synth Preview:** Test your chord progressions on the fly using a built-in Web Audio API synthesizer.
- **Metronome & Tap Tempo:** Precise click track with adjustable BPM (40–240 BPM) and interactive tap-tempo calculation.
- **Night/Day Shift Themes:** Ergonomic high-contrast themes designed for late-night studio sessions or bright daytime practice.
- **100% Offline & Private:** Runs entirely client-side in your browser with zero login walls or external server tracking.
- **Single-File Architecture:** Lightweight, fast, and easy to deploy or modify.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Deploy instantly via GitHub Pages using the included GitHub Actions workflow.

---

## 📂 Repository Structure

- `index.html` — The core single-file application (UI, Web Audio API logic, and styling).
- `repo.js` — Shared Crisp Suite repository metadata helper.
- `manifest.json` — Progressive Web App (PWA) manifest configuration.
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment pipeline.
